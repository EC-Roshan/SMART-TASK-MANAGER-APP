```xml
<color name="ic_launcher_background">#1976D2</color>
```

Blue background color for the logo

### 2. **ic_launcher_foreground.xml** (NEW!)

```xml
<vector ...>
  <!-- Clipboard with checklist design -->
  <!-- Checkmarks and task lines -->
</vector>
```

The actual logo design

### 3. **ic_launcher.xml** (Adaptive Icon)

```xml
<adaptive-icon>
    <background android:drawable="@color/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```

### 4. **ic_launcher_round.xml** (Round Icon)

For devices that use circular icons
